## Каркас файла (обязателен, менять нельзя)

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="generator" content="HTML Note 0.1">
<title>Название документа</title>
<script type="application/json" id="hn-settings">{"toc":true}</script>
</head>
<body class="hn-page">
<main class="hn-doc">
<div class="hn-canvas">
  <div data-type="frame" class="hn-frame" data-x="40" data-y="32" data-w="860" data-bg="#1f2024" data-border="line" data-pad="xl">
    <!-- всё содержимое документа здесь -->
  </div>
</div>
</main>
</body>
</html>
```

- `<meta name="generator" content="HTML Note 0.1">` обязателен: по нему редактор понимает, что это его файл, и открывает его без потерь.
- `"toc":true` включает содержание из заголовков, `false` — выключает.
- Стили и скрипты не пиши: HTML Note добавит своё оформление при первом сохранении.
- Всё содержимое — только внутри листа `div[data-type="frame"]`. Текст вне абзацев и заголовков не ставь.
- Если нужен второй лист рядом, добавь ещё один `div[data-type="frame"]` в `hn-canvas` с другими `data-x` и `data-y` (например, `data-x="940" data-w="420" data-pad="m" data-bg="#26282d"`).

## Что можно использовать внутри листа

**Текст**
- Заголовки `<h1>`–`<h4>`: один `<h1>` в начале, дальше `<h2>` и `<h3>`. Из них собирается содержание.
- Абзацы `<p>`. Внутри: `<strong>`, `<em>`, `<u>`, `<s>`, `<code>`, ссылки `<a href="https://…">`.
- Цвет текста: `<span style="color: #ffa94d">…</span>`. Шрифт и размер: `<span style="font-family: Consolas; font-size: 20px">…</span>`.
- Выделение цветом: `<mark data-color="#665a1c" style="background-color: #665a1c">…</mark>` (бери тёмные цвета: #6b2a2a, #6b4a22, #665a1c, #2c5a2e, #1f5650, #1f4566, #3d356e, #5c2f57).
- Выравнивание: `<p style="text-align: center">`, `<h2 style="text-align: right">`.

**Списки**
- `<ul><li><p>…</p></li></ul>` и `<ol><li><p>…</p></li></ol>`.
- Список задач:
  ```html
  <ul data-type="taskList">
    <li data-type="taskItem" data-checked="true"><p>Сделано</p></li>
    <li data-type="taskItem" data-checked="false"><p>Сделать</p></li>
  </ul>
  ```

**Цитата, код, линия**
- `<blockquote><p>…</p></blockquote>`
- `<pre><code>…</code></pre>`
- `<hr>`

**Таблица**
```html
<table>
  <tr><th><p>Заголовок</p></th><th><p>Заголовок</p></th></tr>
  <tr><td><p>Ячейка</p></td><td><p>Ячейка</p></td></tr>
</table>
```

**Картинки**
- `<img src="https://…" alt="Подпись" data-width="75%" data-align="center">`
- `data-width`: от `25%` до `100%`. `data-align`: `left`, `center`, `right`.
- Обтекание текстом: `data-wrap="left"` или `data-wrap="right"` (тогда ширина 30–50%).
- Ставь только прямые ссылки на файлы картинок, которые точно существуют. Не выдумывай адреса. Если подходящей картинки нет, не вставляй её.

**Видео YouTube или Vimeo** — только ссылкой, без встроенного плеера (он не играет в файле, открытом с диска):
`<p><a href="https://www.youtube.com/watch?v=ID_ВИДЕО">Видео на YouTube ↗</a></p>`

**Кнопка-ссылка**
- Заливка: `<p><a class="hn-button" href="https://…">Открыть сайт</a></p>`
- Контур: `<p><a class="hn-button outline" href="https://…">Подробнее</a></p>`

**Спойлер (сворачиваемый блок)**
```html
<details class="hn-spoiler">
  <summary class="hn-spoiler-summary">Заголовок спойлера</summary>
  <div class="hn-spoiler-body"><p>Скрытый текст.</p></div>
</details>
```
Чтобы спойлер был открыт по умолчанию: `<details class="hn-spoiler" open>`.

**Блоки и колонки**
- Блок — оформленный контейнер, внутри него любые элементы, в том числе другие блоки:
  ```html
  <div data-type="block" class="hn-block" data-bg="#26282d" data-border="line" data-pad="m">
    <p>Текст в карточке</p>
  </div>
  ```
- Готовые стили блоков:
  - Карточка: `data-bg="#26282d" data-border="line"`
  - Акцент: `data-bg="#163d43" data-fg="#eef5f2" data-border="none"`
  - Светлая: `data-bg="#fbfaf6" data-fg="#172f34" data-border="line"`
  - Рамка: `data-border="accent"` без `data-bg`
  - Без оформления: `data-border="none"` без `data-bg`
- `data-pad`: `none`, `s`, `m`, `l`, `xl`. `data-height="300"` — фиксированная высота с прокруткой; без него высота растёт по содержимому.
- Колонки — ряд из 2–3 блоков. Внутри ряда только блоки:
  ```html
  <div data-type="row" class="hn-row">
    <div data-type="block" class="hn-block" data-bg="#fbfaf6" data-fg="#172f34" data-border="line" data-pad="m"><h3>Первая</h3><p>…</p></div>
    <div data-type="block" class="hn-block" data-bg="#fbfaf6" data-fg="#172f34" data-border="line" data-pad="m"><h3>Вторая</h3><p>…</p></div>
  </div>
  ```

## Требования к содержанию

- Пиши по-русски, обращайся к читателю на «вы».
- Начни с `<h1>` и короткого вывода (удобно в блоке «Акцент»), дальше — разделы `<h2>`.
- Факты бери из надёжных источников. В конце сделай раздел «Источники» со ссылками `<a href>` на каждый.
- Не выдумывай цифры, цены, даты и адреса. Если что-то не удалось проверить, так и напиши.
- Длинные подробности прячь в спойлеры, сравнения — в таблицы или колонки.
- Тёмный лист: не используй тёмный цвет текста вне блока «Светлая».

## Что отдать

Один файл `.html` целиком, от `<!doctype html>` до `</html>`, без пояснений вокруг. Если можешь создать файл — создай; если нет — выдай весь код одним блоком.
